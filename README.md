#  🏠 Smart Kost Comparison System

## Deskripsi Singkat

Sistem pencarian dan pemesanan kos berbasis web yang dilengkapi fitur perbandingan antar kos (compare) untuk membantu pengguna memilih kos terbaik sesuai kebutuhan mereka.

## ✨ Fitur

### 👤 User (Pencari Kos)
- Registrasi & Login
- Mencari Kos berdasarkan :
  - Lokasi
  - Harga
  - Fasiltas
- Melihat Detail Kos :
  - Foto
  - Fasilitas
  - Harga
  - Deskripsi
 
### 🔥 Fitur Utama: Compare Kos
- Memilih beberapa kos sekaligus
- Menampilkan perbandingan dalam bentuk tabel
- Membandingkan:
  - Harga
  - Fasilitas
  - Lokasi
  - Rating

👉 Membantu user mengambil keputusan lebih cepat tanpa buka banyak halaman

## 🛠️ Tech Stack

- 🎨 Frontend → HTML, CSS, JavaScript  
- ⚙️ Backend → Node.js  
- 🗄️ Database → MySQL

## 👥 Role
- 👤 user → Cari kos, compare, booking, lihat riwayat

---

## 🧩 Struktur Data 

- **User**
- **Kos**
- **Fasilitas**
- **Booking**

Relasi:
- User melakukan booking
- Kos memiliki fasilitas
- User dapat compare beberapa kos
